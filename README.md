# 🤖 AI Chatbot Engine

A full-stack, responsive AI chatbot web application powered by high-performance LLM inference and a clean Django backend architecture.

[![Tech Stack](https://skillicons.dev/icons?i=py,django,js,html,css,sqlite&theme=dark)](https://skillicons.dev)

</div>

---

### 🌟 Key Features

- **Real-Time Conversational Interface:** Handles prompt-response flow with conversation history preservation.
- **Modular Django Architecture:** Clean separation of serializers, API routing, and LLM orchestration.
- **Session Management:** Organizes interactive dialogs with structured database tracking.

---

### 🛠️ Tech Stack

- **Backend:** Python, Django, Django REST Framework
- **Frontend:** HTML5, Modern CSS3, JavaScript
- **Database:** SQLite
- **LLM Engine:** Groq API Integration
